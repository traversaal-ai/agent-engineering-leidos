# Module 1: Recap & Preview (15-Minute Warm-Up)

## Before we start

This is the opening module for this folder, so there is no prior lesson to recap. Get oriented instead.

**You're in the right place if:** you've used ChatGPT or Claude, maybe tried a coding assistant, and want to actually understand what makes something an "agent" rather than copy-pasting from a chatbot and hoping.

## Coming up (Module 1: Introduction to AI Agents and the Agent Harness)

What you'll be able to do after this session:

- Explain, without hedging, the difference between an LLM and an agent
- State the formula: Agent = LLM + Tools/Actions + State
- Tell apart the three levels of agent sophistication: fixed-workflow automation, ReAct reasoning loops, and multi-agent teams
- Explain what an agent harness is, and name its five building blocks
- Trace the agent loop end to end, step by step
- Name Claude Code's five constructs, CLAUDE.md, Skills, MCP servers, Subagents, and Hooks, and say what each one actually provides

**Watch for:** the line "the model thinks, the harness does." Almost everything in this module is elaborating on that one sentence. If you lose the thread at any point, come back to it.

## If you only remember one thing walking into class

> An agent is not a smarter chatbot. It's an LLM wrapped in a harness that gives it tools, memory, and the ability to keep going until a goal is actually met, not until it has said something plausible.

## You'll build the live example yourself

This module isn't just theory. By the end of it, you will have used the PRD Builder in this folder to generate a real PRD for an idea of your own, and handed it to Claude Code to build a real, running app from it, guided by a CLAUDE.md that sets its rules and scope. When the lesson talks about "the harness," you'll have your own CLAUDE.md to open and see a real one, not just a diagram.
