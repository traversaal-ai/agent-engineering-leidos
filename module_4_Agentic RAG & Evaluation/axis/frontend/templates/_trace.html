{# `data-narrate` is read by axis.js, which POSTs and inserts the narration text. It replaces four HTMX attributes that appended the response body into the page — but the endpoint returns JSON (`{step_id, narration, generated}`), so what they would have inserted was a raw JSON object. They never ran at all, because HTMX was never downloaded, which is how that went unnoticed for two milestones. **It points at the Frontend, not the API**, and that was the second half of the same bug. This URL used to be `/api/v1/sessions/{id}/trace/{step}/narrate`, which requires `Authorization: Bearer ` — and the token lives in an `httponly` cookie precisely so no script can read it. So every narration request from the page was a 401, while the acceptance test passed the header itself and stayed green throughout. Without JavaScript the disclosure still opens and explains that narration needs it, rather than appearing broken. #}
