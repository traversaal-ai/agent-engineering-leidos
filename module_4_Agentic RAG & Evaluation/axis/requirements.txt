# What the Vercel function installs. Mirrors `pyproject.toml` minus two things.
#
# **No chromadb.** It pulls onnxruntime, kubernetes and opentelemetry behind it —
# 533MB of site-packages against Vercel's 250MB unzipped function limit, so the
# bundle simply would not deploy. It is not needed: `_build_vector_store` returns
# `InMemoryVectorStore` when the database path is `:memory:`, and `import chromadb`
# sits inside `ChromaVectorStore.__init__` rather than at module scope, so the
# Chroma path is never reached and never imported. See `api/index.py`.
#
# **No uvicorn.** Vercel supplies the server and imports the ASGI app directly.
#
# Local development still installs from `pyproject.toml`:
#   pip install -e ".[dev,vector,parsers]"
